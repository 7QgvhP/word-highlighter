# 0003. 単語一致を VS Code の検索と同じ規則にする

- ステータス: Accepted
- 日付: 2026-10-16（初版のリリース日）

## 背景（Context）

単語一致の判定には、正規表現の `\b` を使う方法など、いくつかのやり方がある。判定がエディタの検索と違うと、同じ単語でも結果が食い違う。

## 決定内容（Decision）

VS Code 標準の検索の単語一致（`isValidMatch`）と同じ規則で判定する。ドキュメントの言語に応じた `editor.wordSeparators` を区切り文字とし、半角スペースとタブを境界の文字に含める。規則の詳細は [spec.md](../spec.md#マッチング)。

## 理由と検討した代替案（Consequences / Alternatives）

- VS Code の検索窓（単語一致 ON）と同じ結果になり、検索の感覚のまま使える。
- 日本語の単語は、前後が区切り文字・空白・行頭行末のときだけ一致する。既定の区切り文字に「、」「。」や全角空白が含まれないため、「日本、」の「日本」には一致しない。
- 内部の細かい挙動は VS Code のバージョンで変わりうるため、`samples/word-match.txt` で実機の検索窓と見比べて確認する。
