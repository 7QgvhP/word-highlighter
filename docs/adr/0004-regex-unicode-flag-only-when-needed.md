# 0004. 正規表現の `u` フラグを必要なときだけ付ける

- ステータス: Accepted
- 日付: 2026-10-16（初版のリリース日）

## 背景（Context）

JavaScript の RegExp は、`u` フラグを付けると、`\-` のような不要なエスケープをエラーにする。一方、`\p{...}` などの Unicode プロパティは `u` フラグがないと使えない。

## 決定内容（Decision）

フラグは `g` を基本とし、パターンに `\p{...}`、`\P{...}`、`\u{...}` が含まれるときだけ `u` を付ける。`\\p{` のようにバックスラッシュ自体がエスケープされている場合は、含まないとみなす。`i` は付けない（大文字小文字は常に区別する）。

## 理由と検討した代替案（Consequences / Alternatives）

- VS Code の検索窓からコピーした正規表現（`\-` を含むことがある）を、そのまま使える。
- 検討した代替案: 常に `u` を付ける → 不要なエスケープでエラーになり、コピーした正規表現が弾かれるため採用しない。
