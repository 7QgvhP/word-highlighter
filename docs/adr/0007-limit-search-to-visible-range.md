# 0007. 検索範囲を表示範囲の前後300行に限定する

- ステータス: Accepted
- 日付: 2026-10-16（初版のリリース日）

## 背景（Context）

ファイル全体を毎回検索すると、巨大なファイルや多数の単語で負荷が大きくなる。正規表現の暴走への自動対策も行わない。

## 決定内容（Decision）

- 検索範囲は、表示範囲（`visibleRanges`）の前後300行とし、スクロール時に再検索する。表示範囲が複数ある場合（折りたたみなど）は、重なる・隣接する範囲をまとめる。
- 編集・スクロールなどによる再描画は、150ms 待ってからまとめて行う。

## 理由と検討した代替案（Consequences / Alternatives）

- 巨大なファイルでも、負荷をほぼ一定にできる。通常のソース（数千行）で単語20〜50個なら、ほぼ体感できない。
- 表示範囲から300行以上離れた位置は、スクロールするまでハイライトされない。
- 検討した代替案: 1行あたりの検索上限、正規表現の暴走時の自動無効化 → 対象外とした（[spec.md](../spec.md#目的とスコープ)）。
