# 0005. Webview を表示専用にし、状態は拡張機能側が持つ

- ステータス: Accepted
- 日付: 2026-10-16（初版のリリース日）

## 背景（Context）

サイドバーの Webview は、非表示にすると破棄される。

## 決定内容（Decision）

- 状態の正は拡張機能側（Extension Host）が持ち、Webview には状態を持たせない。
- Webview は読み込みが終わると `ready` を送り、拡張機能側が現在の状態を送って描画させる（表示状態が変わったときも送る）。
- 操作は Webview からメッセージで拡張機能側に送り、拡張機能側が状態を更新・保存して、結果を Webview に送り返す。

## 理由と検討した代替案（Consequences / Alternatives）

- Webview が破棄・再生成されても、表示が状態と食い違わない。
- 状態の更新と保存が1か所（`store.ts`）にまとまり、テストできる。
