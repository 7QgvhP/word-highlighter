# 使用方法

記載したコマンドのうち、`npm` のコマンドは 2026-11-15 に実行して動作を確認した。
`code --install-extension` は、手元の VS Code に拡張機能をインストールするため実行しておらず「未検証」としている。画面の操作は、コードから読み取った手順で、実機では確認していない。

## 前提条件

- VS Code 1.141 以上（`engines.vscode` は `^1.141.0`）。Windows を対象にしている。

## インストール

[GitHub Releases](https://github.com/7QgvhP/word-highlighter/releases) から vsix をダウンロードし、次のコマンドでインストールする（未検証）。

```bash
code --install-extension word-highlighter-X.Y.Z.vsix
```

VS Code の拡張機能ビューの「…」→「VSIX からのインストール」でもインストールできる。
手元で vsix を作る場合は `npm run package`（[development.md](development.md#ビルド)）。

## 基本的な使い方

1. アクティビティバーの「単語ハイライト」（蛍光ペンのアイコン）を開く。
2. 入力欄に単語を入力し、Enter（または「登録」）で登録する。背景色が自動で割り当てられ、表示中のすべてのエディタで一致箇所が強調表示される。
3. 一覧の各行で、有効/無効（目のアイコン）、単語一致、正規表現、文字色、背景色の変更と、削除ができる。

## ユースケース別の手順

### エディタ上の単語をそのまま登録する
エディタで文字列を選択して、右クリックメニューの「選択テキストを登録」を実行する。選択がないときは、カーソル位置の単語を登録する。

### 色を変える
行の文字色ボタン（「A」）または背景色ボタンを押し、パレットから選ぶ。「色なし」で色を外し、「カスタム」で任意の色を選ぶ。

### 重なったときの優先度を変える
行の左端のハンドルをドラッグして並べ替える。上にある単語ほど優先され、重なった部分には上の単語の色だけが使われる。

### すべてのハイライトを一時的に消す
ビューのタイトルバーの目のボタン、またはコマンド「全体のオン/オフ切り替え」を使う。オフの間は、入力欄の上に「全体オフ(ハイライトは無効です)」と表示される。

### すべての単語を削除する
一覧の「すべて削除」、またはコマンド「すべての単語を削除」を実行し、確認ダイアログで削除する。

## よくあるエラーと対処

| 症状 | 原因と対処 |
|---|---|
| 単語の行に警告アイコンが出て、ハイライトされない | 正規表現が不正。アイコンのツールチップでエラー文を確認し、正規表現を OFF にするか、単語を登録し直す |
| 単語一致 ON で、日本語の単語が一致しない | 日本語は、前後が区切り文字・空白・行頭行末のときだけ一致する。「、」「。」や全角空白は既定では区切り文字ではない（[spec.md](spec.md#マッチング)） |
| 「保存データを読み込めなかったため、このセッションでは変更を保存しません。」と表示される | 保存データが壊れている。通知の「データを初期化」で、壊れたデータを退避してから初期化できる（[spec.md](spec.md#エラー時の挙動)） |
| 正規表現 ON で、大文字小文字を区別せずに検索したい | 大文字小文字は常に区別する。正規表現の文字クラス（例: `[Ff]oo`）で書く |
