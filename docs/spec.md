# 仕様

旧仕様書（`docs/SPEC.md`）の内容を、仕様（本書）・設計（[architecture.md](architecture.md)）・開発（[development.md](development.md)）に分けて移したもの。

## 目的とスコープ

サイドバーに登録した単語を、エディタ上で文字色・背景色つきで強調表示する VS Code 拡張機能。自分用で、vsix を直接インストールして使う（Marketplace には公開しない）。

### やること
- 登録した単語の一致箇所を、表示中のすべてのテキストエディタ（ファイル種別・言語で除外しない）で、文字色・背景色で強調表示する。
- 単語ごとに、有効/無効、単語一致、正規表現、文字色、背景色を設定する。
- 一覧の並び順で優先度を決める。

### やらないこと
データのエクスポート/インポート、設定同期、コメント・文字列内の判定、一覧クリックでのジャンプ、テーマ別の色切り替え、単語数の上限、二重登録のチェック、`settings.json` の設定項目、多言語対応、1行あたりの検索上限、スクロールバーのマーク、最近使った色、太字・下線などの装飾、キーボードショートカットの既定割り当て、ステータスバーの表示、入力欄のトグル、正規表現の暴走対策（自動無効化）、重なったときの「色なし」項目の引き継ぎ、登録した単語の文字列の編集。

## 基本情報

- 拡張機能 ID: `7QgvhP.word-highlighter`（`publisher` と `name`）。変えると保存データが消える。
- 表示名（`displayName`）: `word-highlighter`。コマンドの分類と通知の接頭辞も `word-highlighter`。UI の文言・コマンド名・メッセージは日本語固定（多言語対応なし）。
- 対象: 最新の VS Code 安定版（`engines.vscode` は `^1.141.0`）、Windows のみ。
- 起動: VS Code の起動後（`onStartupFinished`）。サイドバーを開かなくても、保存済みの単語がハイライトされる。
- 信頼されていないフォルダ（制限モード）でも動作する（`capabilities.untrustedWorkspaces.supported: true`）。
- 外部通信なし。テレメトリなし。実行時の依存ライブラリなし。
- `settings.json` に拡張機能固有の設定項目は追加しない。`editor.wordSeparators` を読み取るだけで、`settings.json` は一切書き換えない。

## 機能一覧

### 単語の登録
- サイドバーの入力欄に入力し、Enter（日本語の変換中の Enter は除く）または「登録」で登録する。空文字は登録できず、入力欄に赤枠とエラー文を出す（入力し直すと消える）。登録に成功すると入力欄を空にする。
- コマンド「選択テキストを登録」（`wordHighlighter.addSelection`）: エディタの右クリックメニューとコマンドパレットから実行する。
  - 選択がないときは、カーソル位置の単語を登録する。取得できない場合は通知だけ出す。
  - 複数行にまたがる選択は拒否して通知する。複数の選択があるときは、主となる選択を使う。
- 登録時の設定は、どちらの方法でも同じ。単語一致 OFF、正規表現 OFF、文字色は「色なし」、背景色は背景パレットを順番に循環して自動で割り当てる。
- 一覧の末尾に追加する（既存の優先度を変えない）。二重登録のチェックはしない。登録数の上限はない。

### マッチング
- 検索は行単位。複数行にまたがる一致は対象外。
- 大文字小文字は常に区別する（切り替えなし）。
- 1つの単語の一致は、重ならないように行頭から順に探し、一致した後はその末尾から次を探す（例: `aa` は `aaaa` の0文字目と2文字目に一致し、`aaa` では0文字目だけに一致する）。VS Code の検索と同じ。
- 通常モード: 文字列をそのまま検索する。
- 正規表現モード: JavaScript の RegExp を使う。
  - フラグは `g` を基本とし、パターンに `\p{...}`、`\P{...}`、`\u{...}` が含まれるときだけ `u` を付ける。`i` は付けない。`\\p{` のようにバックスラッシュ自体がエスケープされている場合は、含まないとみなす（[ADR 0004](adr/0004-regex-unicode-flag-only-when-needed.md)）。
  - 空文字への一致（`^`、先読みだけのパターンなど）はスキップし、1文字（サロゲートペアは2コード単位）進めて続ける。空でない一致はハイライトする（例: `a*` は `baab` の `aa` に一致する）。
- 単語一致: VS Code 標準の検索の単語一致と同じ規則（[ADR 0003](adr/0003-whole-word-same-as-vscode.md)）。
  - ドキュメントの言語に応じた `editor.wordSeparators` を区切り文字とし、半角スペースとタブは「空白」として境界の文字に含める。判定は UTF-16 のコード単位で行う。
  - 左境界: 行頭、直前の文字が区切り文字・空白、またはマッチ先頭の文字が区切り文字・空白。
  - 右境界: 行末、直後の文字が区切り文字・空白、またはマッチ末尾の文字が区切り文字・空白。
  - 境界を満たさない一致は捨て、その一致の末尾から次を探す。
  - 日本語の単語は、前後が区切り文字・空白・行頭行末のときだけ一致する（例: 「日本」は「日本語」の中には一致しない）。既定の `editor.wordSeparators` には「、」「。」や全角空白が含まれないため、「日本、」「。日本」「　日本　」の「日本」には一致しない（VS Code の検索窓と同じ）。
  - 正規表現と単語一致が両方 ON の場合は、正規表現の一致に同じ境界判定を適用する。
- 無効（目アイコン OFF）の単語は、一致の位置を確保しない。

### 重なりと優先度
- 複数の単語が同じ位置に一致した場合は、一覧で上にある単語が優先する。
- 行ごとに、優先度の高い単語から順に文字の位置を確保し、確保した位置には、その単語の設定（文字色・背景色とも）だけを使う。
- 優先度の高い単語で「色なし」の項目は、下の単語の色を引き継がず、色なし（エディタ標準の表示）のままにする。両方とも色なしの単語も、位置は確保する。

### 描画
- 装飾は文字色と背景色のみ。
- 背景色は、固定の透明度 0.4 で描画する（設定項目にはしない）。文字色が未設定でも、ライト・ダークどちらのテーマでもテーマ標準の文字が読める状態で、色味だけを付けるため。文字色は不透明で描画する。
- コメント・文字列リテラルの判定はしない。
- 全体オフのとき、または有効な単語がないときは、すべての装飾を解除する。
- 検索範囲は、表示範囲の前後300行（[ADR 0007](adr/0007-limit-search-to-visible-range.md)）。
- 編集・スクロール・表示中のエディタの変更・`editor.wordSeparators` の変更のときは 150ms 待ってから、単語の変更や全体オン/オフのときはすぐに、表示中のすべてのエディタを再描画する。

### サイドバー（Webview ビュー）
- アクティビティバーに専用のアイコン（蛍光ペンの形）を置く。ビューコンテナとビューの名前は、どちらも「単語ハイライト」で、見出しは「単語ハイライト」とだけ表示される。
- 見た目は VS Code のテーマに追従する。c-function-analyzer の解析結果画面にそろえたデザイン（彩度を抑えた配色、11〜12px の文字、細い枠線と 3px の角丸）。
- タイトルバーに、全体オン/オフの切り替えボタンを置く（オンは目のアイコン、オフは閉じた目のアイコン）。
- 全体オフのとき、入力欄の上に「全体オフ(ハイライトは無効です)」と表示する。
- 単語一覧: 見出し「単語一覧」、登録数、「すべて削除」ボタン（登録がないときは無効）。登録がないときは「単語が登録されていません。」と表示する。
- 一覧の1行: 並べ替えハンドル / 目アイコン / 単語 / （不正な正規表現の警告アイコン） / 単語一致ボタン / 正規表現ボタン / 文字色ボタン / 背景色ボタン / 削除ボタン。
  - 単語は、設定した文字色・背景色（背景色は透明度つき）で文字の部分にだけ色を付けて表示し、プレビューを兼ねる。長い単語は末尾を省略し、全文はツールチップで表示する。
  - 無効の行は薄く表示する。単語一致・正規表現ボタンは、VS Code の検索窓のトグルと同じ見た目。
  - 色ボタンは、文字色は「A」をその色で、背景色は色見本を透明度つきで表示する。色なしは斜線。
  - 行のクリックによるエディタ上のジャンプはない。
- 並べ替え: 並べ替えハンドルをつかんだときだけドラッグでき、ドロップ位置を線で示す。並び順が優先度になる。
- 色ボタン: クリックでパレットを表示する（同じボタン、パレットの外のクリック、Esc キーで閉じる）。
  - 文字色・背景色とも16色（ダークテーマでも目立つ明るい色。色の値は `src/colors.ts`）。現在の色には選択中の枠を付ける。
  - パレットの下の「色なし」と「カスタム」で、文字色だけ・背景色だけの設定や、任意の色を選べる。「カスタム」は OS 標準のカラーピッカーを開き、選び終えた時点で反映する。パレットにない色のときは「カスタム」に選択中の枠を付ける。
- 削除: 単語1つは確認なしで削除する。「すべて削除」は確認ダイアログ（モーダル）を出してから削除する。

### コマンド

| コマンド | ID | 実行できる場所 | 動作 |
|---|---|---|---|
| 選択テキストを登録 | `wordHighlighter.addSelection` | エディタの右クリックメニュー、コマンドパレット | 上記「単語の登録」 |
| 全体のオン/オフ切り替え | `wordHighlighter.toggleGlobal` | コマンドパレット | 全体のオン/オフを切り替える |
| 全体をオフにする（現在オン） | `wordHighlighter.turnOff` | ビューのタイトルバー（オンのとき） | 全体をオフにする（コマンドパレットには出さない） |
| 全体をオンにする（現在オフ） | `wordHighlighter.turnOn` | ビューのタイトルバー（オフのとき） | 全体をオンにする（コマンドパレットには出さない） |
| すべての単語を削除 | `wordHighlighter.deleteAll` | コマンドパレット | 確認ダイアログを出して削除する。登録がないときは、その旨を通知する |

ショートカットキーは既定では割り当てない。ステータスバーへの表示はしない。

## 入出力とデータ形式

### 保存するデータ
保存先は `globalState`（全プロジェクト共通）のキー `wordHighlighter.state`（[ADR 0002](adr/0002-store-state-in-global-state.md)）。

```ts
type WordEntry = {
  id: string;            // 一意ID(crypto.randomUUID)
  text: string;          // 登録文字列(前後の空白も保持、空文字は不可)
  wholeWord: boolean;    // 単語一致(既定 false)
  regex: boolean;        // 正規表現(既定 false)
  fg: string | null;     // 文字色(#rrggbb、不透明)、null=色なし
  bg: string | null;     // 背景色(#rrggbb、描画時に固定の透明度を適用)、null=色なし
  enabled: boolean;      // 目アイコン(既定 true)
};
type State = {
  schemaVersion: 1;
  words: WordEntry[];     // 並び順 = 優先度(上が優先)
  globalEnabled: boolean; // 拡張機能全体のオン/オフ(既定 true)
  nextColorIndex: number; // 自動割り当て用カウンタ(既定 0)
};
```

- 色は小文字の `#rrggbb` にそろえて保存する。背景色の透明度は保存しない。
- 形式バージョン `schemaVersion` を持ち、読み込み時に移行処理を通す（現在は `1` のみで、移行処理はない）。
- 全体オン/オフ、各単語の有効/無効、並び順は、再起動後も保持する。

## 制約条件

- 正規表現の暴走（極端に遅いパターン）への自動対策はない。負荷は検索範囲の限定で抑える。
- 単語一致の細かい挙動は VS Code のバージョンで変わりうるため、実機の検索窓（単語一致 ON）と比べて確認する（[development.md](development.md#テスト)）。

## エラー時の挙動

- **不正な正規表現**: 登録は常に正規表現 OFF で行うため、登録時には検証しない。登録後に正規表現 ON にして不正になった場合は、一覧に警告アイコン（エラー文をツールチップに表示）を出し、その単語を無効として扱う（位置も確保しない）。拡張機能全体は止まらない。
- **保存データの破損**: 次のいずれかに当てはまる場合は、破損とみなす。値がない（未保存）場合は、破損ではなく初期状態として扱う。
  - オブジェクトでない。`schemaVersion` がない、現在より新しい、または1未満。
  - `words` が配列でない。`globalEnabled` が真偽値でない。`nextColorIndex` が0以上の整数でない。
  - 単語の `id` が空・重複、`text` が空、`wholeWord`/`regex`/`enabled` が真偽値でない、`fg`/`bg` が `null` でも `#rrggbb` でもない。
- 破損時は、エラー通知を出し、そのセッションでは保存を一切行わず、空の状態で動く（保存済みのデータを上書きしない）。サイドバーにも「保存データを読み込めなかったため、このセッションでは変更を保存しません。」と表示する。
  - 通知の「データを初期化」を押すと確認ダイアログ（モーダル）を出し、「初期化」を選ぶと、壊れた生データを `wordHighlighter.state.corrupted.<ISO 8601の日時>` に退避してから初期化して保存する。退避先のキーは通知で知らせる。
- 「選択テキストを登録」で単語を取得できない、または複数行の選択のときは、通知を出して登録しない。

## 受け入れ基準

- 単語を登録すると、開いているすべてのエディタで一致箇所に背景色が付く。
- 背景色が付いても、ライト・ダークどちらのテーマでも、文字色なしの文字が読める。
- 文字色・背景色をパレットから変更でき、「色なし」にもできる。カスタム色も選べる。
- サイドバーの単語のプレビューは、文字の部分にだけ背景色が付く（サイドバーの幅を広げても、背景色は広がらない）。
- 単語を削除すると、そのハイライトが消える。
- 一覧をドラッグで並べ替えると、重なったときの優先順位が変わる。重なった区間では上の単語の設定だけが使われる。
- 単語一致を ON にすると、VS Code の検索の単語一致と同じ結果になる（`foo` は `foo_bar` に一致しない、日本語は前後が区切りのときだけ一致する、など）。
- 正規表現で `\-` のような不要なエスケープを含むパターンも使える。登録後に不正な正規表現になっても、警告アイコンが出るだけで拡張機能は止まらない。
- サイドバーのタイトルバーのボタンで全体オン/オフを切り替えられ、オフのときは入力欄の上に表示が出てハイライトが消える。
- VS Code を再起動しても、登録内容・並び順・無効化の状態・全体オン/オフが保持される。
- VS Code を起動した直後、サイドバーを開かなくても、保存済みの単語がハイライトされる。
- 保存データが壊れていても、保存済みデータを上書きしない。
- `settings.json` が一切書き換わらない。
- `npm run package` で vsix が作成でき、インストールして動作する。
